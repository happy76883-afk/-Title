# -Title

사용법

기본·소·중·대분류 중 선택합니다.
1~4번 메뉴에서 산업·금액(백만원)·충격률(%)을 입력하고 계산합니다. 
결과 표와 카드를 확인하고 CSV로 내보냅니다.

분석 방법
1. 원자료 탐색: 행 항목이 열 부문·최종수요로 흐르는 금액(백만원)을 확인합니다. 
2. 수요 증가 시뮬레이션: 최종수요 증가 시 생산·수입·부가가치 유발액과 상위 연관 산업을 봅니다. 
3. 전·후방 연쇄효과: 후방(상류 공급자 견인)과 전방(하류 중간재 파급) 연결을 비교합니다. 
4. 공급충격 시뮬레이션: 공급/원가 충격(%)이 투입망을 타고 번지는 직접·간접·총파급률(%)을 봅니다.
